Purpose

This document imports stock data for the symbols listed in portfolio.txt, computes basic statistics (moving average, mean, mode, median and standard deviation), and displays the data and visualizations. Functions are defined in technical_analysis_functions.R.

1. Install packages (run once)

install.packages(c("quantmod", "TTR", "rmarkdown", "knitr"))

2. Load functions and portfolio

source("technical_analysis_functions.R")

symbols <- read_symbols("portfolio.txt")
symbols

3. Import stock data

Data is downloaded from Yahoo Finance with quantmod for 2025 and stored as one data frame per symbol.

stocks <- load_stock_data("portfolio.txt",
                          from = "2025-01-01", to = "2025-12-31")
